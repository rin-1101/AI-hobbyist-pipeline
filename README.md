# AI Hobbyist Pipeline

A **16-lesson, project-based AI engineering course** covering hosted and local LLMs, structured outputs, RAG, AI agents, MCP servers, multi-agent systems, evaluation, security and real-world deployment.

**Prerequisites:** Familiarity with Python helps · **Suggested pace:** 6–10 hours per lesson · **Method:** Learn → Build → Test → Deploy.

## How to use the course

1. Open lesson [01](lessons/01/README.md) and follow the files in order: **theory → hands-on → resources**.
2. Build each lesson's mini-project; mark required tasks complete and record your results.
3. Progress only after you pass its exit check. Lessons link to previous and next modules.
4. Use the [complete original syllabus](AI_Hobbyist_Roadmap_2026.md) for a high-level roadmap, reference architecture and technology radar.
