# AI Hobbyist Pipeline

A 16-lesson, hands-on roadmap for building and deploying AI applications: LLMs, local models, RAG, agents, MCP servers, multi-agent systems, evaluation and production infrastructure.

**Suggested pace:** 6–10 hours per lesson. Start with the [first lesson](lessons/01_llm_apis_and_inference/README.md), follow theory → hands-on → resources, and complete the exit check before advancing.
