# Hands-on — Capstone, benchmark, and publish

[Overview](README.md) · [Theory](theory.md) · [Resources](resources.md)

## Build

Finalize Personal AI Workbench or a capstone from Section 5.

## Implementation workflow

1. Create a project directory and reproducible Python environment.
2. Define inputs, outputs, security boundaries, and expected errors.
3. Implement a minimal working version and run it locally.
4. Add tests for expected, edge, and failure cases.
5. Demonstrate or deploy the project as required.
6. Record benchmark results, known limitations, and next improvements.

## Required exercises

- [ ] Run ingestion end-to-end and demonstrate sourced RAG answers.
- [ ] Demonstrate an agent using your MCP server in a controlled workflow.
- [ ] Demonstrate an approval gate, a refused unauthorized action, and agent recovery after restart.
- [ ] Include a deployment walkthrough, architecture diagram, 50-case evaluation report and screenshots.
- [ ] Tag a Git release (e.g., `v1.0.0`) and publish a sanitized portfolio demo if allowed.

## Deliverables

- [ ] Working project with setup and run instructions.
- [ ] Reproducible tests or screenshots of results.
- [ ] No secrets or private information committed to Git.
- [ ] Notes on at least one failure and how it was resolved.

## Definition of done

> Another developer can install, test and deploy your project from its documentation.
