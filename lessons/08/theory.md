## Learning objectives

text-to-SQL safety, structured data retrieval, document/table/figure processing, routing data sources, GraphRAG, multimodal RAG and their tradeoffs.

5. **GraphRAG** — Define the idea in your own words, explain when you would use it, and identify one failure mode or trade-off.
6. **multimodal RAG and their tradeoffs** — Define the idea in your own words, explain when you would use it, and identify one failure mode or trade-off.

## Architecture and design questions

1. What problem does this lesson's technique solve better than a simple deterministic script?
2. Where does information enter and leave the system? Which components are trusted?
3. What happens if a model is wrong, times out, or becomes unavailable?
4. How would you measure whether your implementation works?
5. What would change if you had to run the project locally or deploy it for another user?
